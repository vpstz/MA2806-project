A summary of the project.
This project is a one page informative website that shows the decline of use in tabacco in the UK, based on different critirias, age ethnicity and geographical location etc.
The project also covers diseases and deaths that are caused my the use of tobacco. Funny enough I am a part of the smoking population in the UK and this became my inspiration for this project as the idea intrigues me, the other day I was walking past some kids and Ive been getting weird stares from them and it really makes me wonder why. Another funny thing is that the UK proposed to ban tobacco purchase for those born after 2009 while I was working on the project.
